# ペットセレモニーファミリア LP

Astro・SCSS・GSAP で制作した、訪問ペット火葬・葬儀のランディングページです。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:4321` を開いてください。

## コマンド

- `npm run dev` — 開発サーバーを起動
- `npm run build` — 本番用ファイルを `dist` に生成
- `npm run preview` — 本番ビルドをローカル確認

画像素材は `src/assets/images` に配置し、Astro の `Image` コンポーネントで最適化しています。favicon と OGP 画像のみ `public` に配置しています。
